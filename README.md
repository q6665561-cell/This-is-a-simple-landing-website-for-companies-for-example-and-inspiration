Fanntom – A Landing Page for a Web Development Studio
A simple, responsive, and fast one‑page website (landing page) for an IT studio.
Created as an example of a “clean” landing page without frameworks, heavy animations, or unnecessary dependencies.

Features
🧩 Minimalistic design – inspired by light tones and readability.

📱 Fully responsive layout – works correctly on any device (from phones to desktops).

⚡ High loading speed – all code is vanilla HTML/CSS/JS, no third‑party libraries.

🔄 Random contacts – phone number and email are generated randomly on page load (handy for testing or demo).

🧭 Smooth scroll – anchor navigation without abrupt jumps.

🎨 Light interactivity – hover effects on cards and buttons, no overload.

Site Structure
Header – logo and navigation (Services, Benefits, Contacts).

Contact strip – two random phone numbers + a call‑to‑action button.

Hero block – a short USP and a call to action.

Services – three cards with descriptions and prices.

Benefits – 4 key points explaining the value.

Contacts – central block with phone, email, and a trigger button.

Footer – copyright notice.

Technologies
HTML5

CSS3 (flexbox, grid, media queries)

Vanilla JavaScript (contact generation, smooth scroll, minimal interaction)
